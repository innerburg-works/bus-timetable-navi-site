プライバシーポリシー

最終更新日：2026年11月28日 ／ 対象アプリ：バス時刻表ナビ（iOS）

「バス時刻表ナビ」（以下「本アプリ」）は、利用者のプライバシーを尊重し、以下のとおり個人情報および利用者情報の取り扱い方針を定めます。

1. 取得する情報と利用目的

  • 位置情報（GPS）：現在地周辺のバス停を地図に表示し、バス停までの距離・徒歩所要時間や、観光スポットの該当都道府県を自動選択するために使用します。位置情報は原則として端末内で処理され、開発者のサーバーへ個人を特定する形で保存・蓄積・第三者提供することはありません。ただし、地図画面または路線図画面でシェアサイクル表示を有効にした場合は、後述のとおり地図の表示範囲と中心座標が中継サーバーへ送信されます（現在地を地図中心としている場合、その周辺の位置を示します）。位置情報の許可は下記の利用状況の分析同意とは別個に設定されます。
  • お気に入り・言語設定・分析同意設定：登録されたお気に入りバス停、言語設定、および利用状況の分析に関する同意状態は、ご利用の端末内（ローカルストレージ / UserDefaults）に保存されます。
  • 利用状況の分析データ（任意・事前同意制）：アプリの品質向上・機能改善のため、利用者の事前同意を得た場合に限り、Google Analytics for Firebase を利用してアプリインスタンス識別子に紐づく画面遷移や機能利用回数などの利用状況データを収集します（広告パーソナライズおよび広告トラッキングには使用しません）。初期状態では収集は無効であり、初回起動時の選択およびアプリ内メニューの「利用状況の分析」設定からいつでも有効化・停止できます。収集されたデータは Google Analytics の標準保持期間（最大14か月）に従い管理され、停止後は新規データの送信を行いません。データ削除に関するお問い合わせはサポートページよりご連絡ください。詳細は Google のプライバシーポリシー をご確認ください。

2. 外部サービス・APIとの通信

本アプリは、以下の外部サービスから時刻表・リアルタイム運行情報・地図タイル・周辺施設情報を取得するため通信を行います。

  • 開発者運用の中継サーバー（Cloudflare Workers：bus-timetable-navi-proxy.innerburg-works.workers.dev）：
    • シェアサイクル空き台数の取得：地図画面または路線図画面でシェアサイクル表示をオンにして地図を表示・移動・拡大縮小した際に、表示範囲の緯度経度（min_lat / max_lat / min_lng / max_lng）、地図の中心座標（lat / lng）、取得件数上限（limit）を中継サーバーへ送信します（地図を現在地中心に表示している場合、送信座標は現在地周辺を示します。ユーザー識別子や端末識別子は送信しません）。中継サーバーは ODPT 公開 GBFS フィード（ドコモ・バイクシェア、HELLO CYCLING）から該当範囲のポート情報を抽出して返却します。中継サーバーのプログラム上では利用者の座標や履歴をデータベース等に保存する処理はなく、応答高速化のため小数点3桁に丸めた範囲キーで最大45秒間のエッジキャッシュを行います（プラットフォーム側の標準アクセスログ等の保持設定は Cloudflare の既定仕様に従います）。
    • リアルタイムバス接近情報の取得：バス接近情報対応停留所・路線を開いた際に、対象事業者フィード識別子を送信し、公共交通オープンデータセンター（ODPT）および各事業者・自治体の GTFS-RT 情報を取得して中継します（最大20〜35秒のエッジキャッシュを行います）。
  • GitHub Pages（全国公開時刻表・路線図・観光スポットデータ）：選択した都道府県や表示エリアに応じた公開オープンデータの静的JSONを取得します。
  • OpenPOI API：選択したバス停の緯度経度周辺のカフェ情報取得（利用者の個人情報は送信しません）。
  • OpenStreetMap：地図タイルの表示。

3. 広告配信について

本アプリは、Google AdMob を利用して画面下部に非パーソナライズ広告を表示します。iOS の App Tracking Transparency による許可ダイアログは表示せず、本アプリは広告識別子（IDFA）を用いたトラッキングを行いません。バス停検索などのために取得する端末の位置情報は広告リクエストに渡しません。

広告に関する選択が必要かを確認するため、起動時にGoogleの同意管理機能（User Messaging Platform）を使用します。対象地域では必要に応じて選択画面を表示します。広告をリクエストできる状態を確認してから非パーソナライズ広告を要求します。選択の変更が必要な地域では、画面下部の「広告のプライバシー設定」から設定を開けます。利用状況の分析への同意は別に選択できます。

Google Mobile Ads SDK は、広告の配信・表示回数の調整・効果測定・不正防止・SDK の改善のため、IP アドレス（おおまかな地域の推定を含む）、端末やアプリに関する識別子、広告の表示や操作に関する情報、アプリの操作やクラッシュ・パフォーマンスなどの診断情報を処理する場合があります。詳細は Google のサービスを使用するサイトやアプリから収集した情報の使用をご確認ください。
